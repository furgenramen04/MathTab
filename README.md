Welcome to MathTab! It's a new tab page where you can access your favourite websites, see the current moon phase, graph a function, and make some calculations. You can access it here: https://furgenramen04.github.io/MathTab/.

How to use the calculator:

Click to activate the calculator's ability to access keyboard input.

Use A for ANS.

Use Backspace/Delete for DEL

Use Return/Enter for =

Use the respective number buttons for numbers.

Use * for multiplication, / for division, + for addition and - for subtraction.

Use S for Sin, C for Cos and T for Tan.

Use Shift + 2 to activate 2nd mode.

If you do something like press 6, then press Sqrt, then the calculator assumes that you have requested (6 x sqrt).


How to use the grapher:

Type in any function without any syntax errors in the form: y=... or simply ...


How to use the links bar:

Use the Add button, then enter a name and the website link to add a website to the bar.

To remove a site, hover over its icon and click the "x" to remove it.
